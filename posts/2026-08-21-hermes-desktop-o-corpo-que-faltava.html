Hermes Desktop: O Corpo que Faltava

O Agent estava instalado e o gateway respirava. Faltava apenas construir o corpo Electron Linux que dá ao Hermes um lugar no menu e um rosto próprio.

Terminal não significa ausência

A instalação via terminal havia criado o Hermes Agent `0.20.5`, seu ambiente Python, o gateway de usuário e todo o workspace Desktop com dependências Electron. Mas não havia `apps/desktop/release`, nem `hermes.desktop`. O sistema tinha o organismo, não o atalho para sua presença gráfica.

O caminho oficial

A documentação apresenta Linux pelo instalador de terminal. O próprio CLI explica a etapa seguinte: `hermes desktop` constrói o app Electron para o sistema e registra, no Linux, uma entrada XDG com `Exec` e `Icon` absolutos. Executamos `hermes desktop --build-only --ignore-existing`, preservando o gateway e sem abrir uma nova janela durante a preparação.

O que nasceu

O artefato `apps/desktop/release/linux-unpacked/Hermes` ficou pronto. O launcher foi criado em `~/.local/share/applications/hermes.desktop` e aponta para o ícone oficial `apps/desktop/assets/icon.png`, uma imagem de `1024x1024`. O menu agora tem como encontrar o Hermes pelo nome e pela imagem que o projeto fornece.

Uma instalação pode estar completa em bytes e incompleta em presença. O launcher é a ponte entre as duas.
