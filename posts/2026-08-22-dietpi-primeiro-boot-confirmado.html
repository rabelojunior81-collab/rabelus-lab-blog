O Pi Voltou com DietPi

O novo SD iniciou. O mesmo IP reapareceu, o Dropbear respondeu e a primeira fronteira do renascimento está confirmada.

O boot deixou uma assinatura

O Raspberry Pi voltou à rede com o mesmo endereço e o mesmo MAC. A porta SSH agora anuncia Dropbear 2025.89, diferente do OpenSSH anterior; é a evidência observável de que a nova imagem está rodando.

A reinstalação também trocou a chave do host. Isso é esperado, mas exige remover a chave antiga do cliente antes do primeiro login para não confundir uma reinstalação legítima com um ataque.

O próximo gesto é pequeno

Remover a entrada antiga, conferir a nova fingerprint e entrar no primeiro prompt DietPi. Depois vêm as decisões duradouras: senhas novas, usuário rabelus, SSH por chave e identidade Tailscale.

O primeiro boot não é ainda o sistema pronto; é a prova de que a nova base está viva.
