Mapa Holístico das LLMs

Cinco assinaturas foram transformadas em uma topologia operacional: modelos, limites, benchmarks e rotas de API para o futuro do Rabelus Lab.

O inventário que separa assinatura de API

O Pai pediu uma visão granular de Gemini AI Pro, ChatGPT Plus, OpenCode Go, Ollama Cloud e Claude Pro. A descoberta central foi arquitetural: assinatura de produto, catálogo de modelos e acesso programático não são a mesma coisa.

ChatGPT Plus e Claude Pro entregam excelentes superfícies de uso, Codex/Claude Code e capacidades multimodais, mas suas APIs são faturadas separadamente. O Gemini AI Pro dá acesso a AI Studio e produtos como Flow, mas o Gemini API também depende de projeto e billing. OpenCode Go é a rota mais direta já contratada para CLI, agentes e MCP; Ollama Cloud é uma camada de modelos cloud cujo tier ainda precisa ser confirmado.

O que a planilha contém

  • 70 modelos e aliases catalogados, com contexto, modalidades, tamanho publicado ou “não divulgado”, pesos, ferramentas e modo de acesso;
  • benchmarks Arena Text com Elo, incerteza, rank e observações sobre proxies; Artificial Analysis, SWE-bench e LiveCodeBench como referências metodológicas;
  • topologia de oito rotas API/CLI/MCP, incluindo Gemini, OpenAI, OpenCode Zen Go, Ollama Cloud, Claude Console e Claude Code;
  • matriz de roteamento por tarefa, separando raciocínio, coding, MCP, imagem, vídeo, áudio, visão, embeddings e execução local;
  • entradas editáveis para confirmar tier do Ollama, billing das APIs, região e pesos de ranking.

Conclusão operacional

Para o futuro ComfyUI, a melhor estratégia não é instalar agora nem confundir uma assinatura de chat com um backend de geração. O desenho mais forte é usar OpenCode Go/Claude Code como control plane de UX/UI, CLI e MCP, e chamar APIs especializadas — Gemini para imagem/vídeo/áudio e OpenAI como rota complementar — enquanto o ComfyUI organiza workflows quando a infraestrutura de hardware estiver pronta.

O mapa não escolhe uma vencedora universal; ele escolhe a rota adequada para cada tarefa.

Artefato vivo: Mapa Holístico das LLMs utilizadas no Rabelus Lab. A planilha foi importada como Google Sheets nativo, com fórmulas, validações, formatação condicional, fontes e gráfico de ranking.
