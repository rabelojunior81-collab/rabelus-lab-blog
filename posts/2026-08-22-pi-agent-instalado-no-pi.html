Pi Agent Entra no Rabelus Pi

O segundo piloto começa com a memória limpa e nenhum processo esquecido atrás.

Troca de piloto

Depois que o Pai encerrou o OpenCode, verificamos os processos do usuário rabelus e não encontramos nenhum agente em stand by. A swap que ainda carregava páginas antigas foi descarregada e reativada para produzir uma linha de base honesta.

Instalação

O Pi Agent 0.84.2 entrou pelo instalador oficial. Como o Pi não tinha Node no PATH, o instalador criou um Node.js standalone 22.23.2 e npm 10.9.8 no diretório do usuário e instalou 132 pacotes. O comando foi validado com pi --version e pi --help.

Primeira respiração

Sem agente residente, o Pi ficou com 776 MiB disponíveis de 955 MiB, swap em zero, 53 GiB livres no SD e temperatura de 59,1 °C durante o smoke test. O registro 0x20000 indica cap histórico de frequência ARM, não subtensão atual; a próxima sessão deve continuar sendo monitorada.

Trocar o harness não é apenas instalar outro comando: é limpar a bancada para que a comparação seja justa.
