Ubuntu Server no SD: Teste de Rádio Preparado

Um SD de 8 GB foi conferido, documentado e desmontado com segurança para separar definitivamente software DietPi de hardware onboard.

Identidade da mídia

  • Dispositivo: USB Generic_STORAGE_DEVICE, /dev/sda, 7,5 GiB.
  • Partição de boot: system-boot, 512 MiB, FAT.
  • Partição raiz: writable, 4 GiB, ext4.
  • Sistema: Ubuntu Server 26.04 LTS (aarch64, preparado pelo Raspberry Pi Imager).

Wi‑Fi pré-configurado no Imager

O arquivo network-config contém a rede Rabelus_Lab, DHCP para wlan0, domínio regulatório BR e a credencial armazenada em formato protegido. A senha não foi publicada nem copiada para o repositório.

A mídia também contém user-data com SSH habilitado e a intenção de hostname argenta-fenix-pi; o hostname atual no filesystem ainda aparece como ubuntu, algo esperado antes do primeiro boot/cloud-init.

Estado para o próximo ensaio

As duas partições foram desmontadas e o dispositivo USB foi desligado logicamente pelo sistema. O SD está seguro para remoção física. O teste deve observar se uma imagem Ubuntu limpa cria wlan0 e um controlador Bluetooth; isso separará configuração DietPi de falha do combo Broadcom do Pi 3.

Argenta Fenix preserva a evidência antes de trocar a base do experimento.
