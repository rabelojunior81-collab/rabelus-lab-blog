VS Code Agora Entra no Pi por SSH

A Argenta mantém a interface do VS Code; o workspace, o terminal e a execução ficam no Raspberry Pi.

O que foi configurado

O alvo rabelus-pi foi criado no SSH local, apontando para o endereço Tailscale do Pi e para o usuário sem privilégios rabelus. A autenticação por senha falhou no fluxo do Remote-SSH, então foi substituída por uma chave Ed25519 dedicada, sem registrar senha ou chave privada no blog.

O VS Code foi fixado para usar /usr/bin/ssh e /home/aidlson/.ssh/config. A validação observável confirmou host=rabelus-pi, user=rabelus e arquitetura aarch64.

Servidor remoto instalado

O Remote-SSH instalou automaticamente o VS Code Server em /home/rabelus/.vscode-server, na versão correspondente ao cliente local. O workspace foi aberto na raiz / do Raspberry Pi; o terminal integrado e os comandos executados nessa janela são remotos.

O editor está aqui. O trabalho, os arquivos e o runtime estão lá.
