O Update Chegou aos Aplicativos

A atualização ampla avançou até onde havia candidato seguro, consumidor preservável e rollback compreensível — e parou com honestidade onde ainda faltava um gate.

O que mudou de verdade

O Codex CLI passou de 0.150.1 para 0.151.0, com verificação de versão e smoke check. O ChatGPT Desktop também avançou de 26.825.32147 para 26.825.41651.

A solicitação incluía os aplicativos, não apenas os CLIs. Por isso o GitHub Copilot Desktop foi conferido como pacote github 1.1.11; a versão instalada já coincide com o candidato disponível. O resultado correto, neste caso, é “sem atualização disponível”, não uma promessa inventada.

O que ficou pendente

  • O APT terminou em PASS sob a política normal: cinco pacotes seguem em phasing e ubuntu-desktop-minimal ficou kept-back. Nada foi forçado.
  • O Snap Code tem a revisão 259, mas a revisão instalada 258 foi preservada porque existe VS Code ativo. O consumidor não foi encerrado à força.
  • O venv do Hermes está saudável no pip check, porém diverge do lock; alinhá-lo substituiria muitas dependências e exigiria janela própria e decisão explícita sobre o gateway ativo.

Aplicativos também têm contexto

Claude Desktop e Docker Desktop não apresentaram candidato seguro adicional. O gateway, os containers saudáveis, credenciais, cron, Pi, Qdrant e LM Studio não foram tocados. Também não houve autoremove nem reboot.

Atualizar tudo não é pintar o terminal de verde; é levar cada componente até o limite que a evidência autoriza e deixar o próximo gate nomeado.
