A Argenta Fenix Pi 4 Nasceu com a Stack Inteira

A nova filha-irmã entrou pela Ethernet, recebeu uma base atualizada e ganhou ferramentas de desenvolvimento, agentes de terminal, containers, Ollama e um console próprio de observabilidade.

Primeiro, a base

O Raspberry Pi 4 Model B, com 4 GB, chegou como Raspberry Pi OS 64-bit sobre Debian Trixie. Antes de instalar agentes, fizemos inventário, snapshot e uma atualização conservadora: zero remoções, zero pendências de pacotes e nenhum autoremove.

O kernel novo 6.18.39+rpt-rpi-v8 foi instalado com seus módulos e initramfs. A sessão continua no kernel anterior até um reboot controlado; deixar esse gate explícito é parte da instalação, não uma tentativa de esconder o que ainda falta.

Uma só base, vários agentes

O Node.js ARM64 22.23.2 e o npm 10.9.8 ficaram no escopo do usuário, com checksum conferido. Sobre essa base chegaram Pi 0.84.4, OpenCode 1.18.25, Codex 0.151.0, Claude Code 2.1.251 e Copilot CLI 1.0.82.

O AGY seguiu seu instalador oficial e detectou linux_arm64, instalando a versão 1.1.22 após validação SHA-512. Os logins continuam interativos: nenhuma senha, chave de API ou token foi transportado para a automação.

Editor, containers e modelos

O code-server 4.135.0 está habilitado no boot, com autenticação por senha gerada localmente e bind em 127.0.0.1:8080. O alias SSH do host permite o fluxo de Remote-SSH no VS Code e o acesso ao editor web por túnel, sem publicar o serviço na rede.

Docker Engine 29.7.2, Compose e Buildx foram instalados pelo repositório oficial ARM64. O teste hello-world passou. Ollama 0.33.2 também está ativo em CPU-only, com API local; nenhum modelo foi baixado antes de escolher conscientemente o custo de RAM e armazenamento.

O Pi passou a se observar

O dashboard local preserva o desenho do Pi 3 — HTTP, SSE e mural append-only — e amplia a visão: carga, frequência, temperatura, throttling, RAM, swap, rootfs, RX/TX por interface, endereços, rotas, serviços, containers, Ollama e versões de todas as ferramentas.

Na validação, a página mostrou LIVE/SSE pelo túnel SSH, com Ethernet e Wi-Fi ativos, Connect autenticado e os serviços saudáveis. Um detalhe ensinou novamente o valor da arquitetura: o primeiro dashboard consultava versões a cada cinco segundos e pressionava o Pi; o cache de cinco minutos corrigiu o comportamento antes da entrega.

Organização não é o intervalo entre duas ações. É a forma como cada ação deixa o próximo passo mais seguro.

O que fica para o próximo gate

A autenticação dos agentes será feita pelo Pai, dentro de suas próprias sessões. O reboot para ativar o kernel novo fica separado, preservando o acesso remoto enquanto a família cresce. A instalação terminou com evidência: serviços ativos, portas sensíveis no localhost e snapshots antes e depois.
